1. About the Bot

921 👽 is a Discord bot offering community administration, welcome messages, role assignment, moderation, automatic replies, suggestions, feedback, tickets, giveaways, and related server features. Features depend on each server's configuration.

2. Information Processed

Depending on which features are used, the bot may process Discord user IDs, usernames, avatars, server IDs, channel IDs, role IDs, message IDs, join/leave events, command inputs, and message text relevant to enabled features such as automatic replies, suggestions, feedback, and tickets.

3. Why We Process It

  • To send welcome messages and assign configured roles.
  • To run moderation and server security features.
  • To respond to commands and administrator-configured message triggers.
  • To operate suggestions, feedback, tickets, giveaways, and other community features.
  • To save server-specific preferences and settings.

4. Storage and Retention

The bot's implementation uses local data storage, including JSON-based records, for some configuration and feature information. Stored data may include Discord identifiers and feature-specific records. Data can remain stored while it is needed to operate a feature. Specific retention and deletion behavior may vary by feature; contact the operator to ask about a particular record or request deletion.

5. Services and Disclosure

The bot operates through Discord and its hosting environment. Information necessary to provide the bot's features is processed through those services. Server administrators may also see content submitted in server channels or through moderation and community features, depending on Discord permissions and server configuration. The operator does not intend to sell personal data.

6. Security

The operator seeks to limit access to bot configuration and stored data. However, no service can guarantee complete security. Please avoid submitting sensitive personal information through bot commands, tickets, or public server channels.
